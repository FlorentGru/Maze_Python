# Maze Python

Generates a random maze and solves it, animated step by step in a Tkinter window.

- Generation: recursive backtracking (depth-first wall breaking)
- Solving: recursive depth-first search, drawing the explored path

## Run

Requires Python 3 with Tkinter.

```bash
python3 main.py
```

Grid size (12×16 by default) and window size are set at the top of `main.py`.
